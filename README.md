# 一个用于查询花源燃气余额和用气量的集成，请不要问我花源在哪
# An integration for querying Huayuan gas balance and usage, please don't ask me where Huayuan is.

在 Home Assistant 的「设备与服务」中添加 Huayuan Gas，填入燃气表号。集成通过花源燃气网站查询数据，默认每 24 小时刷新一次。

## 实体

| 实体 | 数据 |
| --- | --- |
| 表端余额、账户余额、欠费金额 | 网站余额详情中的三项金额，单位为 CNY |
| 累计用气量 | 网站提供的表底读数，单位为 m³ |
| 阀门状态 | 网站返回的状态文本 |
| 最近一次充值金额、时间、渠道、序号 | 同一笔最新充值记录。序号沿用网站条目中显示的「N 次」 |
| 燃气费用、累计燃气费用 | 由表端余额和同一结算区间的充值计算 |

## 费用口径

- 原「充值记录」实体保留已有实体 ID，改为显示最近一次实际充值金额。没有新充值时保持上一次的金额，没有历史记录时显示未知。依赖旧版「昨日充值总额」口径的自动化需要调整。
- 首次成功查询会读取网站可返回的充值历史。后续刷新只查询自上次成功采样起的日期范围，并保存最近一笔。遇到网络或解析错误时，会在约 15 分钟后重试。
- 「燃气费用」显示最近两次成功采样之间的估算费用，计算方式为期初表端余额加区间内充值，再减期末表端余额。实体属性 `period_start` 和 `period_end` 标记这段区间。
- 首次成功采样建立基准。余额或充值查询失败时暂停结算，下次成功后计算整个间隔。间隔可能跨越数日。
- 「累计燃气费用」在每次成功结算后更新。升级时会尝试沿用可恢复的旧累计值，第一次成功采样建立新版计算的基准。金额实体使用 `CNY`，已有的长期统计可能需要在 Home Assistant 中处理单位变更。

网站的余额页没有提供表端余额更新时间。若充值记录与表端余额异步更新，区间费用可能暂时偏高，余额补记时也可能出现负值。以燃气公司账单为准。
