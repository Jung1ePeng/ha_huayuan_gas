# 一个用于查询花源燃气余额和用气量的集成，请不要问我花源在哪
# An integration for querying Huayuan gas balance and usage, please don't ask me where Huayuan is.

在 Home Assistant 的「设备与服务」中添加 Huayuan Gas，填入燃气表号。集成通过花源燃气网站查询数据，每个北京时间整点刷新，查询失败时约 5 分钟后重试。

## 实体

| 实体 | 数据 |
| --- | --- |
| 表端余额 | 网站当前表端余额，单位为 CNY |
| 累计用气量 | 网站提供的表底读数，单位为 m³ |
| 充值记录 | 历史记录包含金额和实际交易时间 |
| 昨日燃气费用、累计燃气费用 | 昨日单日估算值和跨区间累计值 |

## 充值历史

在「开发者工具 → 动作」运行 `huayuan_gas.refresh_recharge_history`，即可为已加载的燃气表重新抓取网站可查的全部记录。查询成功后才会替换已保存的明细，这个动作只更新充值历史。

「充值记录」沿用原实体 ID，状态显示交易时间和金额。如果自动化需要最新金额，可读取 `latest.amount` 属性并转成数字。HA 历史时间线按检测时间记录最新一笔，状态文字里的日期是实际交易时间。网站能查到的完整明细在实体的 `records` 属性中，按交易时间从新到旧排列，也包含安装前或同一次刷新发现的多笔交易。

也可以用 HA 内置 Markdown 卡片直接查看完整记录。将下面示例中的实体 ID 换成你的充值记录实体 ID。

```yaml
type: markdown
title: 花源燃气充值明细
content: |
  | 交易时间 | 金额（元） |
  | --- | ---: |
  {% for row in state_attr('sensor.huayuan_gas_chong_zhi_ji_lu', 'records') or [] -%}
  | {{ as_datetime(row.time).strftime('%Y-%m-%d %H:%M:%S') }} | {{ row.amount }} |
  {% endfor %}
```

## 费用和累计曲线

- 「昨日燃气费用」用北京时间昨天和今天各自午夜后 15 分钟内的首个有效表端余额，再加上昨天的实际充值来估算。缺少任一边界读数时显示未知，等连续两天成功采到边界后才有单日值。
- 「累计燃气费用」仍按成功采样间隔独立累计。数据恢复后补算整个间隔，可以跨越数天。
- 「表端余额」「累计用气量」和「累计燃气费用」在临时查询失败时保留最后的有效值，`stale: true` 表示数据停留在上次成功更新。过去已经缺失的历史点不会补写。若开发者工具的「统计」页报告旧单位「元」与 `CNY` 不兼容，可在该页修复统计单位，两者金额数值相同。

网站的余额页没有提供表端余额更新时间。若充值记录与表端余额异步更新，区间费用可能暂时偏高，余额补记时也可能出现负值。以燃气公司账单为准。
